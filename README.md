# Titt's Questionably Reliable Character Generator

A free, single-page D&D character concept generator for The Kobold Guild.

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.

GitHub Pages will publish the generator using `index.html`.

## Notes

- No framework or build process is required.
- The generator is completely self-contained in `index.html`.
- All CSS, JavaScript, and generator data are included in that one file.
- You can edit the data pools directly inside the `DATA` object in `index.html`.

## Current features

- Blank initial state
- Generate Character
- Clear All
- Unlock All
- Copy Character profile
- Click a category name to roll only that field
- Lock individual results
- Clear individual results
- Class-linked subclass database
- Large species, appearance, fashion, weapon, fear, flaw, quirk, secret, worship, alignment, and personality pools
